# PDF Utility · Offline — GitHub Pages

Repository statico pronto per pubblicare:

- Home
- Privacy Policy
- Supporto

## Prima di pubblicare

Sostituisci in `support.html` tutte le occorrenze di:

`INSERISCI_EMAIL_SUPPORTO`

con la tua email reale.

## Pubblicazione su GitHub Pages

1. Crea un nuovo repository GitHub, ad esempio `pdf-utility`.
2. Carica tutti i file di questa cartella nella root del repository.
3. Vai su `Settings > Pages`.
4. In **Build and deployment** scegli:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Salva.

Dopo qualche minuto il sito sarà disponibile indicativamente a:

`https://TUO-USERNAME.github.io/pdf-utility/`
